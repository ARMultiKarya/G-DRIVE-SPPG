Sinkronisasi Cloud (5+ Pengguna)

Data link otomatis tersimpan bersama & real-time
Mode Lokal (Hanya di Komputer Ini)

Data saat ini tersimpan di browser ini. Hubungkan ke database Firebase agar 5 orang atau lebih dapat melihat, menambah, dan mengedit link yang sama secara otomatis dari HP / Laptop mana pun.

URL database dari Firebase Console (berakhiran .firebasedatabase.app atau .firebaseio.com).
📖 Panduan 3 Langkah Buat Database Firebase Gratis:
  1. Buka console.firebase.google.com dan login dengan akun Google Anda.
  2. Klik Add Project (beri nama misal: sppg-gdrive-hub), ikuti hingga selesai (100% gratis).
  3. Di menu kiri, pilih Build > Realtime Database > klik Create Database.
  4. Pilih lokasi (misal Singapore) dan pilih mode Start in test mode (agar tim Anda bisa langsung membaca & menyimpan data).
  5. Salin link URL database di bagian atas tabel, lalu tempelkan ke kolom URL di atas dan klik Hubungkan & Simpan!
